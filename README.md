# PhishReady — Phishing Awareness Training

PhishReady is an interactive, browser-based cybersecurity learning experience. It helps learners recognize phishing through a realistic email simulation, explainable security cues, and a short knowledge check.

## What learners practice

- Identifying suspicious sender domains and look-alike brands
- Recognizing urgency and fear-based social-engineering tactics
- Choosing safe actions: pause, report, and verify through a trusted path
- Completing a scored knowledge check with immediate feedback

## Features

- Security-training dashboard inspired by modern awareness platforms
- Interactive phishing decision: report the message or mark it safe
- Progress and points feedback after each decision
- “Spot the signals” lesson that explains the warning signs
- Reporting playbook for handling suspicious messages safely
- Responsive layout for desktop and mobile browsers

## Run locally

No installation or build step is required.

1. Download or clone the repository.
2. Open `index.html` in a modern web browser.
3. Review the simulated email, make a decision, and complete the knowledge check.

## Technology

- HTML
- CSS
- Vanilla JavaScript

## Educational note

The email, brand, address, and link shown in the exercise are simulated for awareness training only. Never enter credentials after following an unexpected email link; instead, open the official app or type the organization’s known address yourself.
